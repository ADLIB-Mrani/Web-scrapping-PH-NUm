Guide d'installation et d'utilisation

🌟 Fonctionnalités

✅ Extraction automatique 📋 Copie rapide 📄 Export CSV 📦 Export JSON 🔒 100% Privé 🚀 Facile à utiliser

📥 Installation

Étape 1: Télécharger l'extension

Clonez ou téléchargez le repository depuis GitHub:

git clone https://github.com/ADLIB-Mrani/Web-scrapping-PH-NUm.git

Étape 2: Ouvrir Chrome Extensions

  1. Ouvrez Google Chrome ou Microsoft Edge
  2. Tapez chrome://extensions/ dans la barre d'adresse
  3. Activez le "Mode développeur" en haut à droite
📸 Activez le Mode Développeur dans chrome://extensions/

Étape 3: Charger l'extension

  1. Cliquez sur "Charger l'extension non empaquetée"
  2. Naviguez vers le dossier Web-scrapping-PH-NUm
  3. Sélectionnez le dossier et cliquez sur "Sélectionner"
📸 Sélectionnez le dossier de l'extension

Étape 4: Vérifier l'installation

L'icône de l'extension devrait apparaître dans la barre d'outils de Chrome. Si ce n'est pas le cas, cliquez sur l'icône des extensions (puzzle) et épinglez-la.

🎯 Utilisation

1. Ouvrir WhatsApp Web

Allez sur https://web.whatsapp.com et connectez-vous avec votre téléphone.

2. Sélectionner un groupe

Cliquez sur un groupe WhatsApp dans la liste de gauche.

3. Ouvrir les informations du groupe

Cliquez sur le nom du groupe en haut pour voir les participants.

4. Extraire les numéros

  1. Cliquez sur l'icône de l'extension dans la barre d'outils
  2. Cliquez sur "Extract Numbers"
  3. Les numéros de téléphone seront affichés

5. Exporter les résultats

Utilisez les boutons pour:

  • 📋 Copy All: Copier tous les numéros dans le presse-papiers
  • 📄 Export CSV: Télécharger un fichier CSV
  • 📦 Export JSON: Télécharger un fichier JSON

⚠️ Important

⚠️ Utilisation responsable

Cette extension est conçue pour un usage personnel et éducatif. Respectez toujours la vie privée des membres du groupe et assurez-vous d'avoir la permission d'extraire leurs numéros de téléphone.

🔒 Confidentialité

Toutes les opérations sont effectuées localement dans votre navigateur. Aucune donnée n'est envoyée à des serveurs externes. Votre vie privée est protégée.

🐛 Dépannage

L'extension ne fonctionne pas ?

  • Vérifiez que vous êtes bien sur https://web.whatsapp.com
  • Rafraîchissez la page WhatsApp Web (F5)
  • Rechargez l'extension dans chrome://extensions/
  • Assurez-vous que les participants du groupe sont visibles
  • Essayez de cliquer sur "Open Group Info" avant "Extract Numbers"
